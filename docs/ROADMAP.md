# Roadmap

## Now (v1)
Mac app: challenges (3, 40, 120 days, mini repeating, breaks, strict mode), streaks, minimum pass mode, library with admin editing, screen recording presets, menu bar stop control.

## Next
- Microphone and system audio in recordings
- Record a single window, multi-display picker
- Global start/stop hotkey
- Automatic Maghrib and Isha reminder times
- iCloud backup of progress
- Export and import of progress and edited text (JSON)

## Mobile website (PWA)
- Responsive web version that reuses the same content as JSON
- Offline counting and streaks
- Import progress from the Mac app

## Android
- Native Kotlin and Jetpack Compose app with the same challenges, streaks and library
- Screen recording presets through MediaProjection

## Content
- More dhikr and duas
- Urdu and Hindi translations alongside Arabic, Telugu and English letters
- Shared content file so an admin can publish updates
